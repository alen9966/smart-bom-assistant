# 智料单 · BOM 工作台

这是一个完全离线的智能料单助手，用于替代只能接受固定模板的旧程序。它会扫描 Excel 的每个工作表，自动寻找表头并匹配字段；匹配结果可以人工修改，错误会明确指出原工作表、原行号、字段和原因。

## 直接使用

可在线打开（数据仍只在你的浏览器里处理，不会上传）：https://alen9966.github.io/smart-bom-assistant/

V1.36 是面向公司绿盾环境的纯网页版。请先完整解压 ZIP，再双击 `启动料单助手.bat`，程序会在公司默认浏览器中打开。选择 `.xlsx`、`.xls`、`.xlsm` 或 `.csv` 文件即可；所有读取和导出均在本机浏览器中完成，不会上传到网络。不要在压缩包预览窗口中直接运行，也不要再使用旧 EXE。

“更改”保存位置依赖浏览器的文件夹访问能力，建议使用最新版 Microsoft Edge 或 Chrome。若公司安全策略关闭了这项能力，程序会明确提示并继续使用浏览器的系统下载目录。

推荐流程：

1. 选择“导入 AD / BOM”“导入装配清单”或“导入采购清单”。
2. 一次拖入一个或多个原始文件，不必预先修改列名或删除标题行。**原始 BOM 若缺少“装配变量（Variant）”列，程序会以黄色提示，并在“项目信息”卡新增「装配变量」输入框允许手动填写；两者都未填写时按“整机采购”处理，不再阻止生成。** 选择「导入采购清单」时，程序会识别公司采购申请表中的分类行，并只把电阻、电容导出为外协阻容备料单。
3. 检查字段对应关系。绿色通常可直接采用，黄色建议确认；识别错时用下拉框修改。
4. 检查错误与提醒。数量错误会显示原始内容；预览中的值可直接修改。
5. 常用的装配清单、采购清单和外协阻容备料清单会默认勾选（采购导入模式默认仅勾选外协阻容）；选择“每个 BOM 一个 Excel”或“所有 BOM 合并一个 Excel”，填写项目信息后生成。采购清单在填写 PCB板厂后，会从各 BOM 文件名自动识别版号并追加「印制板」。外协阻容数量按「单机数量 × 生产数量」计算。

## Excel 乱码处理

- 程序按文件内容识别真实格式，不只看扩展名。即使文件名是 `.xlsx`，实际内容是 CSV、网页表格或旧式 Excel XML，也会使用对应方式读取。
- 自动尝试 UTF-8、GBK / GB18030、Big5 和西文编码，并优先采用表头可识别、异常字符较少的结果。
- 对旧版 `.xls` 已内置完整中文代码页，不依赖同事电脑上的 Office 版本或系统区域设置。
- 如果自动结果仍不正确，在“确认字段对应关系”右上方选择“简体中文 GBK / GB18030”等编码，再点击“按此编码重读”。国内 AD、ERP、WPS 或老系统导出的文件通常优先尝试 GBK / GB18030。
- 更新同事电脑时请替换整个程序文件夹，不要只覆盖 `index.html`；中文代码页组件位于 `vendor` 目录。

## 批量生成与自定义模板

- “每个 BOM 分别生成”：每个 BOM、每类勾选清单分别生成一个 Excel，全部直接下载，不再打包 ZIP。
- “所有 BOM 合并一个 Excel”：跨 BOM 按物料汇总数量，并在来源追溯中保留源文件、工作表和行号。
- 装配清单、领料单和采购清单已内置用户提供的三份公司现用格式作为默认模板，三个模板互不影响。项目工号、部门、产品型号、项目名称、生产数量和批次会自动填入相应位置。
- 公司默认模板采用“原文件内部填值”方式导出，不重新生成表格，因此字体、字号、颜色、边框、对齐、行高、列宽、合并单元格和打印设置均保持原样；打开视图统一切换为普通视图，避免分页预览造成大片黑灰区域。
- AD BOM 缺少 `Comment/名称` 与 `Footprint/封装` 时，会从常用阻容型号编码推导，例如 `1206B102K202NT → 1nF/2kV、1206C`。
- 领料单和采购清单会按物料类别插入原模板样式的加粗分类行，再列出该类别下的物料。
- 采购清单和外协阻容备料清单合并相同物料时，单机数量按所有来源行累加，并与装机总数、采购总数保持一致。
- 导出时会移除模板中已经失效的计算链和外部链接，避免 Excel 询问“是否更新链接”、显示“已修复”或生成修复日志。
- 同时勾选多个清单时会依次直接下载多个 Excel；浏览器首次询问是否允许下载多个文件时请选择允许。
- 右上角“v1.36 网页版 · 更新日志”可查看各版本改动，完整记录也见 `CHANGELOG.md`。
- 装配清单各数据行（包括超出模板容量的新增行）统一继承完整列样式，避免后半段出现边框和对齐不一致。
- 装配清单导出后，「领料数」为 Excel 公式（单机数 × 本次装配数量）；只需改顶部「本次装配数量」，领料数会自动重算。
- 装配 / 采购 / 外协阻容导出时会对位号等长文本按分隔符换行并自动加高行，避免 Excel 固定行高把内容裁切掉。
- 装配清单「型号」「位号」左对齐；采购 / 外协阻容的「名称、型号」同步左对齐。
- 装配 / 采购 / 外协阻容默认按 A4“适合页宽”打印；装配清单已收窄位号、加宽备注，避免备注列被裁切。
- 导出时会隐藏未使用的模板空行并收束打印区域，避免打印出空白页。
- 字段对应区会列出当前清单需要关注的全部表头：已识别为绿色，缺失为红色，并直接说明缺失会影响哪张清单和哪些列。
- 各公司模板拥有独立的字体和样式定义，勾选几类清单就分别下载几个 Excel，不再生成 ZIP。
- 如需临时换版，仍可分别点击“公司默认模板”上传其他 Excel 模板，并可随时“恢复公司默认”。
- 外协阻容备料清单提升为常用输出，与装配、采购并列默认勾选，并内置公司默认模板。领料单收在“其他报表”中按需勾选。
- 明细表和外购件汇总表收在“其他报表”中，按需展开勾选，并继续支持独立模板。
- 程序会扫描模板前 60 行，自动寻找数量列和物料字段，数据从表头下一行开始填写，并沿用模板数据行的字体、边框、填充和数字格式。
- 模板中可使用 `{{项目工号}}`、`{{产品型号}}`、`{{项目名称}}`、`{{批次}}`、`{{生产数量}}`、`{{使用部门}}`、`{{装配变量}}`、`{{源文件}}`、`{{生成时间}}` 占位符；也可以把这些名称作为标签放在单元格中，程序会填写右侧单元格。
- 模板缺少数量列或物料标识列时不会勉强生成，而会明确提示模板缺少必要表头。

## 智能识别与汇总规则

- 自动扫描前 40 行寻找最可能的表头，支持中英文、常见缩写、不同列顺序和标题行。
- 自动识别失败时，可手动填写表头行号，再指定字段对应关系。
- 数量规则会根据导入模式分别处理：AD / BOM 导入时，常规清单数量按“原数量 × 生产数量”计算；装配清单导入时，领料单、明细表和外购件汇总表保持原数量，不乘生产数量。
- “外协阻容备料清单”筛选电阻和电容，并始终按“原数量 × 生产数量”计算；即使从装配清单或采购清单导入也会单独放大。BOM 模式下自制阻容不会进入外协表。
- 新增「导入采购清单」模式：导入公司采购申请表后，可直接生成外协阻容备料单。
- 阻容识别支持物料名称/类别中的“电阻、电容”，R/C 位号，以及 Ω、pF、nF、µF 等常见规格特征。
- 领料单按物料编码优先汇总；无编码时依次使用厂家料号、型号、名称、图号或装配项目。
- 自动外购判断会排除明确标记为“自制/自产”的行；“外购/采购/标准件”等关键词或存在厂家时视为外购。没有任何属性时，为避免漏采，默认按外购处理，判断依据会写入导出表。
- 有红色错误的行默认不参与数量汇总，但会进入“数据问题清单”，并保留原工作表和行号。

## 输出内容

- AD / BOM 模式：装配清单、领料单、采购清单、明细表、外购件汇总表、外协备料清单。
- 装配清单模式：领料单、明细表、外购件汇总表、外协备料清单；前三类保持原数量，外协备料清单乘生产数量。
- 每个输出工作簿都附“导出说明”；有问题时自动增加“数据问题清单”。

## 开发与测试

项目核心是纯前端应用，桌面版使用 Electron 封装。若要重新安装开发依赖，可执行 `npm install`；运行测试执行 `npm test`。执行 `npm run build:exe` 生成 Windows 便携版 EXE，执行 `npm run build:release` 生成浏览器版 ZIP。
